# Versions of Skypowered

Find what changed in which distributed version of Skypowered.

## Initial Release - 1.0
*Released January 30, 2026*

**Overview Tab**
- Menubar button to add a new device, optionally providing templates for iPhone/iPad
- Enter percentage when charging a device, Skypowered translates to absolute Wh
- Overview cards for overall Wh, saved money, saved CO2 and device count
- Comparison and contextualization of values in card detail views

**Statistics Tab**
- A chart showing the absolute charged amount over time
- Choose a range from 1 week to all-time
- Optionally filter devices

**Settings Tab**
- Option to show welcome page again on next app launch
- Reset all the data inside the app
- Recieve information about the developer and the app
- Weblinks and contact eMail

### 1.1
*Released March 5, 2026*

**Overview Tab**
- Undo charging log up to one minute after saved
- The bottom device card has been removed. Its content is now available via the "Devices" context menu

**Fixes and small improvements**
- Fixed an issue where the slogan on the first Onboarding page wasn't displayed correctly on devices with small screens
- Moved "Skip" button on the template page for new devices below headline and gave it a more prominent look, being called "Create from scratch"
- Improved readability on some Overview Detail Cards
- Bar widths of the statistic now adapt dynamically to their given space
- Fixed an issue where the x-axis showed no labeling when having less values

### 1.2
*Released May 13, 2026*

**Overall**
- The App's interface is now fully available in German
- Added logic for devices that accidentally have no name

**Overview-Tab**
- Choose the date of charge when creating a new entry
- Added iPhone 17e and updated newest battery capacities on iPad

**Fixes and small improvements**
- Bars in the chart are now properly positioned
- Bar width adaption is now more reliable
- Fixed problems with labeling in some cases
- Overall and average per bar values are now shown above a chart
- Choose app language in Settings
